# 🎓 Study Dashboard 2026/2027

لوحة تحكم شخصية تقرأ بيانات الدروس من Notion وتعرض نسب الإنجاز.

## 1) المتطلبات
- Node.js 18+
- Notion Integration لها صلاحية الوصول إلى قاعدة/مصدر الدروس.

## 2) الإعداد

```bash
npm install
```

انسخ `.env.example` إلى `.env` ثم ضع مفتاح Notion:

```env
NOTION_TOKEN=secret_xxxxxxxxxxxxxxxxx
NOTION_DATA_SOURCE_ID=0874e087-7c06-4a81-9d0a-4d7c72e22ca8
PORT=3000
```

## 3) تشغيل

```bash
npm start
```

ثم افتح:

`http://localhost:3000`

## كيف تحسب النسب؟
كل درس له 5 مراحل:
1. الدراسة الأولى
2. المراجعة الأولى
3. المراجعة الثانية
4. مراجعة التثبيت
5. المراجعة الامتحانية الأخيرة

نسبة المادة = عدد علامات الإنجاز في مراحلها ÷ (عدد دروس المادة × 5).

النسبة العامة = جميع علامات الإنجاز ÷ (جميع الدروس × 5).

## ملاحظات Notion
يجب أن تكون خصائص قاعدة البيانات بهذه الأسماء:
- المادة
- الوحدة
- الصفحة
- الدراسة الأولى
- المراجعة الأولى
- المراجعة الثانية
- مراجعة التثبيت
- المراجعة الامتحانية الأخيرة

ومراحل المراجعة يجب أن تكون Checkbox.


## النسخة ثنائية الاتجاه
يمكن للموقع الآن تعديل حالات المراجعة في Notion، وقراءة/إضافة القنوات وقوائم التشغيل. أضف `NOTION_CHANNELS_DATA_SOURCE_ID=43ebac62-0e94-48d6-a7aa-c338554d9e6f` إلى `.env`.

## تسجيل الدخول والحماية
- الصفحة الرئيسية والـ API محمية بجلسة دخول عبر Cookie من نوع HttpOnly.
- بيانات الحساب **لا توجد داخل الكود أو بيانات الموقع**؛ يتم قراءتها فقط من متغيرات البيئة السرية `AUTH_EMAIL` و`AUTH_PASSWORD_HASH`.
- كلمة السر لا تُخزن كنص صريح؛ يتم التحقق منها عبر `scrypt`.
- يجب ضبط `AUTH_EMAIL` و`AUTH_PASSWORD_HASH` و`SESSION_SECRET` في Vercel/الخادم، ولا تُضع القيم الحقيقية داخل Git أو ملفات المشروع.
- بعد تسجيل الدخول تصبح الدروس مقسمة حسب خاصية `الوحدة`، وتظهر وحدة واحدة في كل مرة مع أزرار السابق/التالي.
